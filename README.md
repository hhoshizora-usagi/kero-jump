# ケロの空中遺跡

**ver. 1.1.0**

ブラウザだけで遊べる空中のぼりゲーム。
「ほかのゲーム」枠の見た目・アニメーション改善シリーズ、4本目です。

## 方針

ルール（自動ジャンプ・左右移動・動く足場・壊れる足場・落ちたら終了・ベスト記録）は**従来どおり**。
見た目・アニメーション・画面サイズ対応だけを作り直しました。

## 変えたところ

### 見た目

- **ケロ（カエル）を描きおろした** — 目玉・ほっぺ・おなかの白まで描いたオリジナルキャラ。
  メニュー画面ではふわふわ浮いています。
- **空が高さで変わる** — 登っていくと青空 → 夕焼け → 星空に移り変わります。
  上がれば上がるほど見た目が変わるので、登ること自体が楽しみになりました。
- **足場を描き直した** — 丸みのある岩のブロックに、上面のハイライトと影。
  種類ごとに色と紋章が違うので、遠くからでも判断できます。
  - 緑：ふつう ／ 青：動く（矢印マーク）／ 橙：一度だけ（ひび割れ模様）
- **雲と星を追加** — 遠くの雲がゆっくり流れ、高いところでは星が瞬きます。

### アニメーション

- **ジャンプ** — ケロがつぶれて伸びる（スクワッシュ＆ストレッチ）。
  足場から草の粒が飛び散ります。
- **壊れる足場** — 乗った瞬間にひびが入って消え、橙の破片が舞います。
- **スコアの節目** — 100点ごとに「○点 到達！」が弾けて出ます。
- **落下** — 落ちたときの音と、ランクバッジが弾む結果画面。

### その他

- **音** — Web Audio で合成した効果音（ジャンプ／ひび割れ／落下／到達）。
  外部ファイルなしで鳴ります。
- **操作** — 画面を左右にドラッグ、または `←` `→` キー。
  画面の外側に回り込んでも反対側から出てきます（従来どおり）。
- **画面サイズ対応** — スマホの縦・横・PCに合わせて、フィールドが入りきる最大サイズになります。
- **ベスト記録は保存されます**（localStorage）。
- **動きを控えめに設定している端末** — OSで「動きを減らす」を選んでいると、アニメーションが止まります。

## 変えていない中身

- 自動でジャンプし続ける（止まれない）
- 左右移動して足場に乗る
- 足場は55の間隔で上へ伸びていく
- 動く足場・一度だけの足場
- 左上40%より上に出ると画面がスクロールしてスコアが増える
- 落ちたら終了
